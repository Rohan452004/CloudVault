
# 🚀 Introducing **CloudVault**

A powerful and easy-to-use cloud storage platform built on **AWS S3**!

## 🔧 Choose between:

✅ **Self-Managed Mode** — Connect your own S3 bucket (ideal for devs & startups)  
✅ **Platform-Managed Mode** — Use our AWS-backed storage with **100MB free for demo users**

---

## ✨ Why CloudVault?

- Intuitive dashboard (table & grid view)
- Folder creation, file upload, rename, delete
- Pre-signed link sharing with optional expiry
- Bulk operations & real-time file navigation
